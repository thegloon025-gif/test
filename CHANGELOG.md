- Implemented exact bounded predicate support for the observed `(t:eldrazi or keyword:changeling) t:creature mv>3 mv<7` expression, and recognized the corresponding `Eldrazi Creature Card with MV=4, 5 or 6` display name. Also supports the observed `mv<=1 (mana={0} or mana={1} or mana={C}) is:permanent` template; arbitrary expressions still fail closed.
- Added offline-only startup library repair using hashed requests derived from **verified** imported 100-card decks; no automatic requests to Spellbook, Scryfall, or Archidekt.
- Combo package selection now rejects newly added cards with no commander-specific synergy or independent utility and scores whole-package strategy alignment, existing overlap, commitment cost, commander involvement, and documented outcomes. Preserves original ramp/draw/interaction guards and exact budget/bracket rules.
- Added names/results and matched-template explanation to generated-deck checks; inventory completeness remains explicitly unverified for game-state execution.
- Added six tests (`tests/v083-repair.test.mjs`) and a reduced **user-provided actual API response** regression fixture with 10 included and 115 near variants. Full suite 67/67 passing. This is verified *response shape and local matching*, not a real Scryfall-backed gameplay benchmark. See `benchmarks/v083-VALIDATION.md`.
- Fully unattended community research, live spellbook syncing, actual bracket policy verification, and independent gameplay simulation remain future work.


## v0.8.2 — Combo-aware construction (2026-10-20)

### Added

- `src/comboTemplates.mjs`: fail-closed matcher for explicit type/subtype and mana-value predicates (including 4, 5, or 6; 4–6; bounded comparison queries). Uses castable faces rather than text mentions or transformed-only backs. Rejects unsupported Scryfall searches instead of treating them as a wildcard.
- Named-card quantity/commander-position checks plus wildcard-template inventory matching against distinct named requirements; exposes named completeness, template pending, matching candidates, and *never-verified* execution status.
- Preserves `requires`/`uses` quantities, zones, card states, Spellbook bracket tags, `manaNeeded`, `manaValueNeeded`, and prerequisites rather than dropping them.
- `src/comboLibrary.mjs`: atomic, provenance-labeled cache of normalized API variants by commander. Populated **only** after a successful on-demand `/api/community/combos` request (or a valid previously cached response). Cards/decks can be generated locally even without that cache.
- `src/comboConstruction.mjs`: optional whole-package evaluator with catalog identity, Commander legality/color identity, price, commander strategy, curve limits, game-changer limits, conservative bracket policies and limited extra card slots. The primary generator completes ramp, interaction, draw and plan roles first. Selected cards are protected from budget reinvestment swaps.
- Generator/UI reports locally known variants, selected package cards and matched template replacements, and explicitly never labels card inventory as a mechanically executable win condition.
- Frozen `benchmarks/generator-v081-reference.mjs` and reproducible `tools/compare-v081-v082.mjs` script for real Scryfall cache A/B when supplied.
- `tests/combo-construction.test.mjs` with explicit hand-checked *synthetic* regression cases; current full suite 61/61.

### Compatibility and verification

- Preserved Scryfall, Archidekt imports/discovery, manual Spellbook checks, pricing modes, B2/B3/B4, and existing UI API routes; with no library variants, v0.8.2 chooses the same cards as v0.8.1 on its synthetic control fixture.
- Existing 54 tests remain green (one template test expectation updated because a distinct commander creature is a valid inventory template match). New tests are not misrepresented as live game verification.
- **Not verified:** actual 10 included combinations for Ulalek `test2`, live Spellbook backend behavior, and real-card €191 Ulalek B3/Yuriko/Wilhelt/Light-Paws benchmark. No genuine card catalog, recorded `test2` Spellbook response, or Cardmarket EN NM offer data shipped with the uploaded archive. Outbound DNS to official card/APIs failed during build.
- The supported template grammar and conservative B2/B3 combo restrictions are heuristics; `bracketTag` values are retained without guessing an official numerical mapping. Manual rule, starting-zone, casting-permission, resource and timing review is required.
