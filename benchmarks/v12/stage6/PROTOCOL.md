## Terminal contract and comparison criteria

Five mutually exclusive statuses: completed T8; supported conditional lethal with actual turn; supported model loss; search unknown; runtime unsupported-rule unknown. Unknown takes precedence over an otherwise claimed terminal. Missing T8 observations are null after lethal/loss/unknown. Static unsupported clauses and missing opponent/combat mechanics remain disclosed even in completed runs. Conditional lethal is a supported finite conversion against inert seats, never real-game win probability or complete combo timing.

Primary descriptive endpoints: paired conditional lethal by T6/T8 and model-loss incidence, retaining every pair; unknown event outcomes get full [0,1] identification bounds. Separately, T3/T5/T7 commander presence, realized net card access/draws, paid copy triggers and payable native threats use only pairs with both complete preterminal landmark observations. Publish all omitted identities and denominators. These conditional subsets do not establish whole-deck causal improvement. No fabricated future hands, draws or wins; prefix engine/cascade/outlet counts explain execution only.

Each pilot/decision/partition gets paired nominal 95% deterministic 2,000-resample bootstrap intervals. No pooling pilots as independent observations, multiplicity adjustment or power score. Exploratory, small-sample intervals can be overconfident on ties. Integration readiness requires no adverse terminal identification interval, complete T5 pairs with nonnegative commander/access/threat lower bounds, and a strictly positive commander or net-access lower bound in both partitions for every fixed pilot/decision. This deliberately stringent evidence screen is not a new selection objective. Any missing native coverage forces abstention. Otherwise report inconclusive tradeoffs or supported regressions rather than pick a winner from price, count or a favorable pilot.
